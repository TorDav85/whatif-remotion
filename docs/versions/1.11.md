# Version 1.11 — pilote éditorial

Réponse à la review de la branche `1.10` : améliorer la **rétention** (accroche, textes concurrents,
rythme du récit, mix) sur un seul pilote avant de toucher aux autres épisodes. Les vidéos d'origine
et la version 2.01 ne changent pas.

## Le pilote : `MarcGeantCourt`

45 s au lieu de 83 s, montées à partir des plans de `MarcGeant` (aucun nouveau décor), avec une
nouvelle narration et un nouvel habillage. Sources : `src/videos/marc-geant-court/`.

```bash
npm run voice:marc-geant-court     # voix XTTS + ambiance remontée + sous-titres synchronisés
npm run render:marc-geant-court    # out/marc-geant-court/marc-geant-court-45s.mp4
```

lu à la fois par la composition, le script audio et le rapport éditorial.

## Outils partagés

| Fichier | Rôle |
| --- | --- |
| `src/shared/captions/CaptionTrack.tsx` | Sous-titres en groupes de 6 mots / 32 caractères max., mot prononcé en blanc, mots-clés en or |
| `scripts/audio/captions.py` | `npm run captions -- <slug>` : timings mot à mot (faster-whisper) appliqués au texte du script → `captions.json` |
| `src/shared/ui/OverlayPolicy.ts` | Modes `story` / `science` / `climax` / `end` et ce qu'ils autorisent à l'écran |
| `src/shared/ui/PlatformSafeArea.ts` | Zones sûres TikTok / Shorts |
| `src/shared/ui/transitions.ts` | Coupe franche par défaut, fondu au noir seulement sur les coupes `dip` |
| `scripts/check/editorial-report.mjs` | `npm run editorial` → `out/editorial-report.md` |
| `scripts/check/audio-levels.py` | `npm run audio:levels -- <slug> [mp4]` → `out/audio-levels/<slug>.json` |
| `src/videos/<slug>/publication.json` | Variante d'accroche et de montage, métriques YouTube Shorts et TikTok séparées |

`Scene3D` de `marc-geant` accepte une option `clearStreet` (caméra de la minute 5 sur la chaussée,
sans voiture garée au premier plan) ; sans l'option, l'original est inchangé.

### MP4 du pilote

45,0 s, H.264 1080×1920 30 i/s, AAC stéréo 48 kHz, 42,9 Mo. Planche : `review/1.11/planches/marc-geant-court.png`.

### Voix

Transcription de chaque réplique (faster-whisper `small`). Deux mots mal compris ont été reformulés
plutôt que régénérés au hasard : « plier » (entendu « appuyer ») → « céder » ; « les avions frôlent »
(entendu « les viens ») → « il frôle les avions ». Restent des homophones sans gravité
(« ses os » / « ses eaux »), à confirmer à l'oreille.

### Tests

`npm test` passe : typage, 36 tests caméra/ville/release 2.01, test projet, validation
(4 avertissements « verify » préexistants sur nature, nature-v2, gravity, whatif).
