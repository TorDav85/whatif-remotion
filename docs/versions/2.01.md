# Version 2.01

Version visuelle du 1er novembre 2026 : les 19 vidéos narratives existantes et le
film AudioFirst conservent leurs caméras, leurs durées, leur montage et leurs pistes
audio. Les versions 2.01 sont regroupées dans **Videos-2-01** dans Remotion Studio,
avec le suffixe `-V201` ; les compositions d'origine restent accessibles.

Les personnages et la bibliothèque détaillée sont repris dans les vidéos. Les
anciens décors sont prolongés par des quartiers irréguliers ; les arrière-plans
suivent la végétation, les ruines, la neige et la chaleur du récit. Les menuiseries
du kit historique reçoivent des croisillons en relief. Les scènes de parc gardent
leur horizon végétal. Une légère finition du contraste et des couleurs est
appliquée sans recadrer l'image.

Le catalogue exact est `src/releases/v2-01/catalog.json`. Les empreintes du fichier
`camera-lock.json` sont vérifiées avant les rendus. Les métadonnées de chaque
composition 2.01 sont comparées à celles de son origine au moment du rendu.

```powershell
npm run check:2.01
npm run stills:2.01
npm run render:2.01
# Un seul film, ou reprise d'un lot interrompu :
node scripts/export/release-2.01.mjs render --only marc-geant
```

Les fichiers sont écrits dans `out/2.01/<film>/<film>-2.01.mp4`. Le rapport
`status.json`, la galerie `index.html`, les planches de contrôle et les rapports de
décodage restent dans ce dossier. Le lot reprend les MP4 déjà validés lorsque les
sources et leurs pistes audio ont la même empreinte.

Les voix sont conservées. Les prises dont la transcription était déjà contrôlée
réutilisent ce contrôle uniquement si le WAV conserve la même empreinte. Chaque
MP4 est décodé entièrement et une image extraite est comparée au PNG de référence.
L'étiquette publique est **2.01** ; la version npm équivalente est **2.1.0**.
