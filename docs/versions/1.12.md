pour qu'une nouvelle vidéo ne recopie pas les défauts du code. Part de la branche `1.11`.

## P1 — Robustesse et partage du code

- **Dépendances croisées supprimées** : kit instancié, tour Eiffel, contours des terres, quartier de Paris,
  personnage articulé, `Actor`, four géant et liste de plans déplacés vers `src/assets/` et `src/shared/`
  (tableau et règle d'imports dans [docs/structure.md](../structure.md#ce-qui-est-partagé)).
  Seuls restent les imports entre versions d'une même histoire.
- **`src/shared/three/shots.ts`** : `shotAt` / `cutsOf` partagés par 9 vidéos (Marc ×8, Astéroïde).
  `MarcGeant` et `InternetOffV1` gardent leur variante (tremblement, orbites).
- **Commandes historiques unifiées** : les 21 scripts `render:*` / `still:*` des bases du catalogue
  passent par `scripts/project/video.mjs` (validation et cache d'ambiance par empreinte) ;
  les 18 crochets `prerender` / `prestill` en `--if-missing` sont retirés.
- **Validateur** (`npm run validate`) : avec `audio.voice` actif, chaque `beat-N.wav` doit exister et tenir
  dans son créneau ; pour les vidéos `narration.json` + `voice.json`, chaque piste doit exister, tenir dans
  son `slot` et ne pas chevaucher la suivante. Un audio exclu de Git manquant est un avertissement.

**Garantie de non-régression** : `npm run compare:stills -- <dossier-1.11> …` rend les mêmes images depuis
les deux versions. Résultat sur 20 vidéos touchées, 40 images : **écart 0** sur toutes.

## P2 — Contenu, visuel, légal

- **Bulles ancrées** : `projectToScreen` (même caméra que les scènes) + `SpeechBubble` ; dans InternetOffV1,
  chaque réplique suit la tête de la personne qui parle et reste dans la zone sûre.
- **Vérification factuelle** : les 12 affirmations `"verify": true` (nature, nature-v2, gravity, whatif)
  ont maintenant un champ `source` :
  - trou noir de masse terrestre : luminosité d'Eddington 1,26×10³¹ W × 3,0×10⁻⁶ ≈ 3,8×10²⁵ W ≈ 1/10 du Soleil ;
    énergie de liaison de la Terre 2,24×10³² J ÷ 3,8×10²⁵ W ≈ 68 jours → « environ 70 jours » confirmé ;
  - gravité coupée : l'air n'est plus retenu par le gradient de pression (accélération initiale ≈ g),
    ≈ 17 km en 60 s, au-dessus des avions de ligne ;
  - Paris sans humains : ordres de grandeur de Weisman (2007) et *Life After People* (2008).
  Validation : 0 avertissement.
- **Licence des voix** : [docs/legal/voix-et-licences.md](../legal/voix-et-licences.md). La CPML de XTTS v2
  n'autorise que l'usage non commercial du modèle **et de ses sorties** (aucun paiement direct ou indirect) :
  une chaîne monétisée doit changer de voix. Modèle d'accord de consentement inclus.

## P4 — Automatisation

- **GitHub Actions** (`.github/workflows/ci.yml`) à chaque push et pull request : `npm ci` → `validate` →

  en WebGL logiciel (`REMOTION_GL=swangle`), planches et rapport publiés en artefact.

## Protection de `main`

À appliquer une fois la CI passée au moins une fois (le contrôle `checks` doit exister) :
Settings → Rules → Rulesets → New branch ruleset → cible `main` →
« Restrict deletions », « Block force pushes », « Require a pull request before merging »,
« Require status checks to pass » avec `checks`.
